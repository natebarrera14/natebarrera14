## Featured project

### [YouTube to Agent](https://github.com/natebarrera14/youtube-to-agent)

A workflow for turning build tutorials into reusable agent skills with an evidence trail. It combines local video frames and captions with a separate Gemini reading, then preserves agreement, uncertainty, and conflicting claims in a build specification.

**Explore:** [Case study](https://github.com/natebarrera14/youtube-to-agent/blob/main/docs/case-study.md) · [Worked example](https://github.com/natebarrera14/youtube-to-agent/blob/main/examples/meta-ads-tutorial/README.md) · [Skill](https://github.com/natebarrera14/youtube-to-agent/tree/main/skills/youtube-to-agent)

**What I contributed:** workflow requirements, evidence and approval rules, AI-assisted implementation, review of discrepancies, and packaging into a reusable skill.

**Current scope:** an agent-guided workflow, Python video-reader helpers, and a documented tutorial example. The standalone command remains a scaffold; the repository explains the boundary and verification.
